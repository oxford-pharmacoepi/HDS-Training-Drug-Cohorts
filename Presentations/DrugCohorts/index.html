What cohorts are we going to create?


Amoxicillin

  1. Drug ingredient of amoxicillin and descendants
  2. Collapse gaps less or equal to a week
  3. First ever exposure
  4. Require to be adults (≥ 18 years)

Amoxicillin oral route

  1. Drug ingredient of amoxicillin and descendants but only with oral route
  2. Collapse gaps less or equal to a week
  3. First ever exposure
  4. Require to be adults (≥ 18 years)

Amoxicillin + clavulanate combination oral route

  1. Drug ingredient of amoxicillin and descendants but only with oral route
  2. Collapse gaps less or equal to a week
  3. First ever exposure
  4. Require to be adults (≥ 18 years)

Amoxicillin oral route

Rather than including all amoxicillin concepts, we might want to restrict to only those of a certain route

amoxicillin_oral <- getDrugIngredientCodes(cdm = cdm,

  setNames("amoxicillin_oral")

→ Create treatment episodes and identify new users

We now combine exposures into treatment episodes and apply our new-user criteria:

cdm$amoxicillin_new_users <- cdm$amoxicillin |>
  # Collapse exposures separated by ≤7 days
  collapseCohorts(
    gap = 7,
    name = "amoxicillin_new_users"
  ) |>
 # First ever exposure
 requireIsFirstEntry(name = "amoxicillin_new_users") |> 
 # Adults
  requireAge(ageRange = c(18, 150),
    name = "amoxicillin_new_users"
  )

Step 3: Reviewing cohorts

Run PhenotypeR diagnostics

phenotypeDiagnostics() allows us to run all the phenotyper diagnostics checks. Drug diagnostics is not run by default, so we will likely want to switch this on

result <- phenotypeDiagnostics(
  cdm$amoxicillin_new_users,
  databaseDiagnostics = list(),
  codelistDiagnostics = list(drugDiagnostics = TRUE),
  cohortDiagnostics = list(),
  populationDiagnostics = list()
)
shinyDiagnostics(results, here::here())
